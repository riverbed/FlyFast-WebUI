# Unit 1 Domain Entities - Tracing Core Modernization

## Entity 1: TracingRuntimeState
Purpose:
Represents current tracing lifecycle state for the frontend runtime.

Attributes:
- status: Uninitialized | Initializing | Initialized | Degraded
- initializedAt: timestamp | null
- initializationReason: string | null
- isReusable: boolean

Relationships:
- One-to-one with TracingProviderConfiguration
- One-to-many with TracingDiagnosticEvent

## Entity 2: TracingProviderConfiguration
Purpose:
Represents resolved runtime configuration used to initialize tracing.

Attributes:
- serviceName: string
- exporterEndpoint: string
- processorMode: Batch | Simple | Hybrid
- environment: Development | Production | Test

Relationships:
- Owned by TracingRuntimeState
- Referenced by TracerAccessContract

## Entity 3: TracerAccessContract
Purpose:
Represents standardized accessor interface to retrieve tracer handles.

Attributes:
- tracerName: string
- accessorVersion: string
- isAvailable: boolean

Relationships:
- Depends on TracingRuntimeState == Initialized
- Used by CustomTracingOperation

## Entity 4: CustomTracingOperation
Purpose:
Represents a business operation wrapped with custom tracing logic.

Attributes:
- operationName: string
- operationType: LegacyPromiseWrapper | EnhancedCallbackWrapper
- startedAt: timestamp
- completedAt: timestamp | null
- outcome: Success | Error | Cancelled

Relationships:
- Creates SpanLifecycleRecord entries
- Uses TracerAccessContract

## Entity 5: SpanLifecycleRecord
Purpose:
Represents span lifecycle semantics generated by wrapper logic.

Attributes:
- spanName: string
- spanKind: string
- status: Unset | Ok | Error
- startTime: timestamp
- endTime: timestamp | null
- attributes: key-value map (non-sensitive)

Relationships:
- Belongs to one CustomTracingOperation
- Emits zero-to-many TracingDiagnosticEvent entries

## Entity 6: TracingDiagnosticEvent
Purpose:
Represents diagnostic events for initialization and wrapper execution.

Attributes:
- eventType: InitializationFailure | WrapperFailure | RuntimeWarning | CompatibilityFallback
- eventTime: timestamp
- message: string
- safeContext: key-value map (sanitized)

Relationships:
- Associated with TracingRuntimeState and/or SpanLifecycleRecord

## Entity Relationship Summary
- TracingRuntimeState governs lifecycle.
- TracingProviderConfiguration configures runtime behavior.
- TracerAccessContract provides tracer retrieval abstraction.
- CustomTracingOperation uses access contract to create spans.
- SpanLifecycleRecord tracks operation span semantics.
- TracingDiagnosticEvent captures safe diagnostics across all entities.

## Boundary Constraints
- Domain excludes route-specific and web-vitals-specific logic (handled in Unit 2).
- Domain excludes test implementation details (handled in Unit 3).
